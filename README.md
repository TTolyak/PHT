# 🎯 HabitTracker

Простой веб-сайт для отслеживания привычек.

> ⚠️ Основной функционал (раздел привычек) находится в разработке.

 # Реализованный функционал

- 🔐 Смена пароля
- 🖼 Загрузка аватара профиля
- 🌓 Смена темы оформления (светлая/темная)

 # Технологии

- Python + Flask
- SQLAlchemy (ORM)
- HTML/CSS/JS
